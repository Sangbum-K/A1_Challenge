3식 0 · A₂ 출력에서 값 꺼내기

A₂는 가로 40칸(bin) 각각에 대해 7개 채널을 낸다. 가운데 10칸(bin 16~25)이 자기 차로 앞쪽이다.

실차용 변경 선행차 bin 선택 (선배 F2는 i₂ 특징을 직접 봤기 때문에 이 단계가 없었음)

4식 1 · 규칙 gate

선배가 학습 gate 이전에 실제로 배포했던 규칙이다. 학습 gate는 이 규칙을 따라 하거나(distill) 개선하도록(beat) 학습됐다.

선배 원본 매 A₂ 프레임 t마다
st = maxk ∈ {16,…,25} At[k, 0]
graw,t = σ( (st − θ) · κ ),  σ(x) = 1 / (1 + e−x)
gt = β · gt−1 + (1 − β) · graw,t
기호의미값출처
st프레임 t의 앞차 점수: 가운데 10칸 앞차 logit 최댓값-선배 원본
θ문턱. s = θ이면 graw = 0.5 (logit 0.3 ≈ 확률 0.57)0.3선배 원본 GATE_THRESH
κ기울기. 클수록 문턱 주변에서 0↔1로 빨리 바뀜5.0선배 원본 GATE_SCALE
graw,t평활 전 순간 gate (0~1)-
β평활 계수. 이전 값을 얼마나 유지할지 (21 Hz에서 시정수 약 0.13 s)0.7선배 원본 GATE_EMA
gt최종 gate: 앞차를 얼마나 믿고 브레이크를 적용할지0~1
g0시작값0실차용 변경 시작 시 브레이크 개입 없음
주의 θ, κ, β는 시뮬 A₂ 점수를 기준으로 맞춘 값이다. 실차 A₂는 점수 분포가 다르다(9/27 60 cm 앞차 프레임 확률 중앙값 약 0.63). 처음에는 선배 값 그대로 쓰고, 9/27 로그로 재생해 gate가 너무 자주 꺼지거나 켜지지 않는지 본 뒤 조정한다.

5식 2 · P5 감속식

9주의 · 미검증 항목

상대속도 vrel 9/27 60 cm 로그의 앞차 프레임에서 종방향 상대속도 중앙값이 +12.3, +4.9 m/s였다(90 cm 정지 차량 +10.2 m/s). 양수 편향은 “앞차가 멀어진다”로 읽혀 브레이크가 덜 걸리는 방향이다. 앞차 정지 + 자차 접근 실험(실제 접근속도 = CAN 속도)으로 검증하기 전까지 식 0의 교차 확인을 쓴다.
  • 설계안이며 아직 구현·실행하지 않았다.
  • A₂가 최종 모델 버전이 아니다. 파일을 찾으면 교체한다.
  • gate 상수는 시뮬 A₂ 기준이다. 9/27 로그로 먼저 확인한다.
  • tH = 1 s 읽기, g0 = 0, 교차 확인은 선배 코드에 없는 우리 선택이다.
  • F1 목표속도 계획(vref)과 aF1은 F1 확정 후 연결한다.
  • 처리량(21 FPS), 인지 정확도, 제어 결과는 각각 따로 판정한다.

10규정 관점: 선배 방식과 우리 방식

선배 방식: 문제없었음

backbone(신경망) → A₂(신경망) → F1(신경망) → F2(신경망) → gate(신경망)
  • 각각 따로 학습했지만 전부 신경망이다.
  • 그래서 하나의 그래프로 이어 붙이면 “하나의 신경망”이 된다.
  • 규정(선배 해석)은 따로 학습하는 것을 금지하지 않았다. 실행할 때 전체가 신경망 하나로 이어져 있기만 하면 됐다.

우리 방식: 걸릴 수 있음
