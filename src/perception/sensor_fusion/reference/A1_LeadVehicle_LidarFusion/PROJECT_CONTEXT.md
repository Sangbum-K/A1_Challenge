# 프로젝트 인계 — 2026-10-12

사용자 요청: 기존 P5 결과를 바탕으로 별도 프로젝트를 설계하고, 필요한 자료는 경로 의존 없이 복사한다. 로컬/GNSS와 충돌하지 않으며 LiDAR 10 Hz를 기준으로 한다. 기존 A₂의 차량 존재/bin만 사용하고 카메라 거리·속도 출력은 무시한다. 기존 SOTA 리포의 활용 방안을 비교한다.

결정: C++17/ROS 2 실시간 + Python 분석. 기존 리포의 CenterPoint + multi_object_tracker를 우선 도입할 계획이며, A₂ 후단 보조와 BEVFusion을 각각 비교한다. 현재 분석은 자체 군집/Kalman이었고 센서퓨전은 수행하지 않았다.

작성/완료: README, 전체 설계, 백엔드 비교, 미정 보정값을 명시한 설정 계약, C++ 기본 P5 수치 CLI, 차등 테스트. 기존 모델/가중치/기준 코드/분석 결과/로컬 설정 62개 파일을 복사했다. SHA256 62개 모두 일치. `bash verify.sh`에서 C++ 빌드 및 42개 테스트 통과(기존 37 + 새 5, 새 차등 테스트 내부 203개 수치 사례).

미구현: ROS 메시지 패키지/실시간 노드, Autoware/NVIDIA 백엔드 및 가중치 설치, 카메라 bin 어댑터, 원시 rosbag 재생 도구의 경로 독립 이식, 차량 통신. 원본 스냅샷은 보관 전용이며 절대 경로를 가진 원본 스크립트를 새 런타임에서 실행하지 않는다. 원시 bag은 미복사.

검증 한계: 수치 일치 테스트는 실차 제어 검증이 아니다. 외부 보정/시간 동기/INS velocity 계약은 아직 미확정. 이번 `nvidia-smi`는 드라이버 통신에 실패하여 GPU 추론 성능을 확인하지 못했다. 기존 로컬/GNSS 설정, 네트워크, 드라이버, TF, 원본 파일은 변경하지 않았다.
