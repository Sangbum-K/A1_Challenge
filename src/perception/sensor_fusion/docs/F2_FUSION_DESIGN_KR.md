# 최종 목표: 카메라 대상 선택 + LiDAR 거리/속도 → F2

2026-11-03 사용자 확정: 최종 경로는 fusion이다. 카메라 단독 metric 모드는 비교용이다.
카메라는 A₂ ch0 존재 logit와 bin 영역만 제공한다. LiDAR 군집을 카메라 bin에 투영해
동일 대상을 대응한 뒤, 해당 트랙의 실제 위치/거리/상대속도를 사용한다.
A₂ ch6 거리와 ch3 상대속도는 융합 계산에서 읽지 않는다. 이미 C++ 코어 시험은
카메라 metric 채널 전체가 NaN이어도 LiDAR 융합이 동작하는지 검증한다.

## 입력 정의

- base X: 차량 전방, Y: 좌측, Z: 위쪽.
- 사용자 확인: LiDAR -Y가 차량/카메라 전방. LiDAR +Z가 위라는 가정에서
  base_from_lidar yaw=+π/2. 센서 평행이동, roll/pitch, 미세 yaw는 미측정이다.
- `d`: 대응된 LiDAR 군집의 관측 표면 최소 base X − 자차 전방 범퍼 X (m).
  LiDAR 중심부터의 유클리드 거리를 범퍼 간격과 혼용하지 않는다.
- `v_rel`: 추적한 선행차 속도 − 자차 속도를 차량 전방축에 투영 (m/s).
  음수이면 접근, 양수이면 이격이다.
- `v_ego`: 유효한 자차 종방향 속도. 기본 입력은 사용자 요청의 GNSS 내장 IMU 적분이다.
  현재 raw IMU 미수신이며, 장시간 속도 정확도를 확보한 상태는 아니다.
- `v_lead=max(0, v_ego+v_rel)`; 전진 주행만 다루는 현재 모델의 가정이다.

## F2 식: 기존 P5와 호환되는 제동 전용 기준안

실차 파라미터 확정 전 shadow 계산 기준으로 현재 코드와 동일한 식을 유지한다.

```text
s_t = 대응된 카메라 bin의 A₂ ch0 logit
q_t = sigmoid(5 × (s_t − 0.3))
g_t = 0.7 × g_(t−1) + 0.3 × q_t

P5_t = P5_profile(v_ego, d_LiDAR, max(0, v_ego + v_rel_LiDAR))
a_F2 = −min(3.0, g_t × max(0, −P5_t))       [m/s²]
```

`a_F2`는 -3..0 m/s²의 부호 있는 **제동 가속도 요구값**이다. 가속 요구를 내지 않는다.
제동 크기를 양수로 표현하면 `brake_decel_mps2 = −a_F2`이다.
3.0 m/s²는 기존 소프트웨어 제한을 유지한 값이며 차량의 검증된 제동 한계라는 뜻이 아니다.
gate는 새 A₂ 시각마다 한 번만 갱신한다. 동일 A₂를 LiDAR callback에서 재사용할 때 중복 갱신하지 않는다.
EMA 계수 0.7은 처리 주기에 의존하므로 현재 21Hz 카메라/약 10Hz LiDAR 실행 주기에서
실제 갱신 주기와 반응 지연을 후속 검증해야 한다. 기존 기준과의 수치 호환을 위해 지금 변경하지 않는다.

P5_profile은 기존 선배 코드와 일치하는 40개(0.1초 간격) 속도 profile이다.
최소 간격 `7 + 6 log(1 + v_ego/5)`, 시간 간격 2초로 초기 profile을 만들고,
후방 decel 20 및 전방 accel 5 m/s² 제한을 적용한다.
`P5=(u[10]−u[0])/1초`, `u[0]=v_ego`이다.
이 profile의 내부 제한 20은 최종 제동 출력 제한 3과 서로 다른 값이다.
실제 주행 계산에는 `plan_speed_mps=-1`을 사용한다. 임의 계획속도 what-if는 실차 명령 대상이 아니다.

## 유효성과 CAN 경계

카메라 이력 미충족, 시간/장착 미보정, IMU 미수신/만료, 트랙 미확정, 대상 대응 모호,
거리/속도 비정상이면 F2 숫자를 확정하지 않는다: `valid=false`, `request_mps2=NaN`,
`reason`, `valid_until`을 사용한다. 소실을 자동으로 제동 0(해제)으로 바꾸지 않는다.
소실 시 유지/감쇠/다른 제어기 전환 정책은 실제 제어기 통합 때 별도로 정한다.

현재 ROS `BrakeEstimate.request_mps2`가 위 a_F2에 해당한다. CAN 송신 코드는 없다.
가속도 m/s²를 CAN의 페달 %, 압력 또는 원시 정수로 변환하는 식은 DBC 단위/스케일과
차량 제동 응답 측정이 있어야 정할 수 있다. 임의의 ×100 변환을 사용하지 않는다.
F1과 F2의 최종 중재 방식도 아직 미정이며, 현재 F2 단독 계산을 F1에 더한다고 가정하지 않는다.
