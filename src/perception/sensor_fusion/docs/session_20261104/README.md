## 2. 적용 완료된 변경

- `association.cpp`: Autoware.Auto 설계의 거리 적응형 XY 연결을 참고한 자체 C++ 구현. 두 점 모두의 반경 조건을 만족해야 연결한다. 거리 구간별로 점군을 분리하지 않아 구간 경계 단절을 피한다.
- 연결 반경: 20m까지0.45m, 이후 거리1m당0.01m 증가, 최대0.85m. 인접점 높이 차이 최대1.2m. 최소 군집5점 유지. 이 수치는 현장 초기값이며 논문에서 보장한 값이 아니다.
- 기존 차량의 부분 관측: 과거 정상 크기 관측 이력이 있으면 수평 긴 변0.8m 이상 / 높이0.15m 이상 /5점 이상인 부분 군집을 유지한다. 트랙 소실 시 이력도 소멸한다. 모든 작은 물체를 차량으로 승격하지 않는다.
- 원거리 신규 부분 관측: 거리20m 이상, 누적6회 이상 대응, 긴 변0.8m 이상, 높이0.3m 이상 등을 요구한다. 학습 기반 차량 분류는 아니다.
- 관측 크기 변화 시 XY 측정 공분산을 축별로 늘려 군집 중심 변화가 속도에 그대로 반영되는 정도를 줄였다. 급접근 반응·형상 변화에 대한 실측 검증은 미완료.
- 기존 coast0.3초 / memory0.8초, 가까운 주 대상1대·대기1대, 카메라 독립 LiDAR 주 대상 선택 유지.
- 원시 점 처리 및 Patchwork++ 지면 추정 범위100m, 전방 군집 처리100m, BEV 표시100m. **P5 후보 범위는 기존10~50m 유지**. 가까워지는 기존 주 대상은10m 아래에서도 유지한다.
- 카메라 진입0.50→0.40. 유지0.35 / bin 경계0.25 유지. 정확도 개선 입증 아님; 배경 오검출 관측됨.
- CSV에 트랙별 geometry 판정·점 수·크기, 10m 구간별 input/nonground/voxel/elevated 점 수 진단 추가.
- 현재 `run_ui.sh`는 `csv_path`를 기본 전달하지 않으므로 **현재 실차 런에서 이 CSV는 생성되지 않았다**. 합성/재생 시험 CSV에는 기록됨. 실차 수치는 별도 ROS 관측 JSONL로 보존했다. 다음 실행에서 `-p csv_path:=...` 전달 또는 런처 기본 연결 필요.

## 4. 다음 작업 — 아직 구현되지 않은 내용

1. **최우선: XY 점군의 차량 방향에 맞춘 회전 상자(OBB) 길이/폭으로 최대 크기 검사.** 현재 AABB의 좌우 폭2.6m 제한 때문에 옆모습 차량 탈락. 단순히 모든 최대 크기를 늘리는 것으로 대체하지 말 것.
2. OBB 방향 불안정·부분 관측·옆 차량 합쳐짐을 시험하고, 앞/뒤/옆모습 및 회전 중 ID·속도 연속성을 확인.
3. 실차 CSV 진단을 원커맨드 런처에 연결. 지면 제거 과잉 여부는 구간별 점 수와 원시 점군으로 확인한 후 수정. 지면 조건은 이번에 일괄 완화하지 않음.
4. 원거리 실제10→50m와50→100m 시험, 차량2대 분리·가림·재접근·오검출 평가. 부족한 점을 예측으로 무기한 채우지 않음.
5. 카메라0.4/0.5 비교는 실제 차량/배경 정답을 붙여 평가. 낮춘 값에서 왼쪽 배경 반응이 관측됨.
6. 실제 센서 세부 모델 및 명판/제조사 규격 확인. 런타임 `6_1 XTM1 parser` 이름만으로 제품 모델 확정 금지.
7. 카메라 내부/외부·시간 보정, GNSS IMU 입력 확보는 별도 남은 작업. 트랙·주행라인 연동은 사용자 요청으로 보류.

## 5. 근거 논문·공식 저장소

- [Autoware.Auto Euclidean clustering 설계](https://autowarefoundation.gitlab.io/autoware.auto/AutowareAuto/euclidean-cluster-design.html): XY 연결, 거리에 따른 임계값, 양쪽 점 임계값 충족 원칙을 반영. 코드를 복사한 것이 아니라 원리를 참고한 자체 구현.
- [Patchwork++ 공식 저장소](https://github.com/url-kaist/patchwork-plusplus), [IROS 2022 논문](https://arxiv.org/abs/2207.11919): 기존 지면 제거 구현 유지. 처리 범위를100m로 설정했으며 정확도 검증을 대체하지 않음.
- [adaptive_clustering 연구 저장소](https://github.com/yzrobot/adaptive_clustering): 비교 검토. 해당 패키지를 통째로 도입한 것은 아님.
- [Hesai 공식 XT32 매뉴얼](https://www.hesaitech.com/wp-content/uploads/2023/03/XT32_User_Manual_X01-en-220410.pdf): 검색 결과에 instrument range120m /80m@10% 표기. 본문 도구 접근 실패, 장착 세부 모델 미확정이므로 우리 센서의 규격으로 단정하지 않음. 사용자 설명100m는 소프트웨어 처리 범위 설정에 반영했으며100m 차량 검출 보장이 아님.
