# 카메라·LiDAR 보정 절차

값은 `cpp/config/calibration.yaml` 한 곳에만 넣는다. 측정 전에는 검증 플래그를 켜지 않는다.

## 왜 필요한가

현재 fx=640은 초기값이다. 2026-11-05 주행 영상에서 LiDAR 박스가 차 옆으로 어긋났고,
일부 구간의 차 폭과 위치에서 fx 약 1030~1170이 추정됐다. 다른 구간은 값이 흩어져 yaw나 시간 오차도 섞여 있다.
추정값을 그대로 넣지 말고 아래처럼 측정한다.

## 1. 내부 파라미터

1. 실제 주행과 같은 ROI(1280×720, offset 320/240)로 카메라를 켠다.
2. 체커보드를 화면 전체에 걸쳐 30장 이상 찍는다. 가장자리와 기울임을 포함한다.
3. `camera_calibration` 또는 OpenCV `calibrateCamera`로 계산한다.
4. `camera_fx`, `camera_fy`, `camera_cx`, `camera_cy`, `camera_distortion: [k1, k2, p1, p2]`에 넣는다.
5. 재투영 오차가 1 px를 넘으면 다시 찍는다.

ROI를 바꾸면 cx, cy가 바뀌므로 다시 측정한다.

## 2. 외부 파라미터

1. LiDAR와 영상에 모두 보이는 표적을 10, 20, 30, 50 m에 둔다. 평평한 사각 표적이나 세운 판이 좋다.
2. 각 거리에서 LiDAR의 표적 중심과 영상의 표적 중심을 기록한다.
3. `camera_rpy_rad`, `camera_position_m`을 조정해 투영 오차를 줄인다.
4. 줄자로 잰 장착 위치를 먼저 넣고 각도만 맞추면 값이 흔들리지 않는다.

## 3. 판정

- 모든 거리에서 재투영 오차가 1 bin(32 px) 이하이면 `calibration_verified: true`로 바꾼다.
- `base_from_lidar`의 값과 `bumper_x_m`도 실측값으로 바꾼다.
