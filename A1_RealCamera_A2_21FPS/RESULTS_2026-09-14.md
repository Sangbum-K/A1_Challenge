# 2026-09-14 실물 카메라 A₂ 실험 요약

## 한 줄 결론

Hikrobot 카메라의 실제 `1280×720 BayerRG8` 입력에서 software resize 없이
`camera_aravis2 → ROS2 → backbone/i₁ → 21-frame A₂ → a₂`를 **지속 21 FPS로 실행하는 데
성공했다.** 다만 모니터 재촬영 영상에서 차량 반응은 불연속적이어서 sim-to-real 정확도는
아직 통과로 판정하지 않는다.

## 최종 보존 결과

| 실험 | 목적 | 핵심 결과 | 판정 | 상세 보고서 |
|---|---|---|---|---|
| 1280×720, 15000 µs, FP32, 60초 | 순수 처리량 | a₂ 20.998 FPS, compute p95 15.214 ms, 유실 0 | **PASS** | [RESULT.md](outputs/real_camera_1280x720_exp15000_fp32_60s/RESULT.md) |
| 1280×720, 25000 µs, 화면+MP4+raw A₂, 60초 | 화면 반응성 | a₂ 20.996 FPS, 주행 구간 lead 검출률 53.67% | **처리량 PASS / 반응성 PARTIAL** | [RESULT.md](outputs/real_camera_1280x720_exp25000_visual_60s/RESULT.md) |

두 실험 모두 카메라 수신 frame은 `1280×720`, hardware Offset은 `(320,240)`, 모델 crop은
수신 frame의 `x=0:1280`, `y=235:485`다. 21 FPS와 21-frame은 서로 다르며, 21-frame은
현재 token 1개와 0.05–1.00초의 과거 token 20개를 뜻한다.

## 해석

- 기술적 실행 가능성: **확인 완료**
- 카메라 수신, BayerRG8 debayer, ROS2 QoS, CUDA 추론: **확인 완료**
- 60초 동안 21 FPS, history 중복 0, NaN/Inf 0: **확인 완료**
- 모니터 영상에 대한 object 반응: **확인했지만 불연속적**
- 실제 거리와 상대속도 정확도: **미검증**
- 실제 차량 적용 판단: calibration/FOV 정합 및 timestamped GT 실험 필요

실험 결과에 포함되지 않는다. 처리량 PASS를 실제 차량 인식 정확도 PASS로 해석하면 안 된다.
